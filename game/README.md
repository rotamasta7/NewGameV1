# Aussie Bites — Web Build (Phase 1)

A playable 5-reel x 3-row, 25-line slot machine. Fun credits only — no real money.

## What works now
- Spinning reels with staggered left-to-right stops
- Credits, adjustable bet, win meter
- 25 paylines, win detection, Golden Gaytime **Wild** substitution
- Argo Cone **Scatter** detection (3+ shows a "Canteen Frenzy coming soon" message)
- Placeholder symbols (coloured tiles + emoji) — real cut-out art drops in later

## How to run
It's a static site — no install, no build step.

- **Locally:** open `game/index.html` in any browser. (Tip: `Space` = spin.)
- **Shareable link:** the repo can be served via GitHub Pages or a static host
  so friends can play on their phones without installing anything.
